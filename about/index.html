About · 데이터 분석 · 데이터 엔지니어링 지향

데이터를 이해하고,
사용할 수 있는 결과로 연결합니다.

컴퓨터공학을 바탕으로 데이터 분석과 데이터 엔지니어링을 주력으로 준비합니다. 백엔드·프론트엔드·Cloud/DevOps는 분석 결과를 기능으로 전달하고 실행 상태를 확인하는 보완 역량입니다.

01

관심의 출발

친구들과 게임을 즐길 때에도 참여하는 것보다 직접 로컬 서버를 구성하고 운영하는 과정에 더 흥미를 느꼈습니다. 포트 포워딩과 서버 설정을 조정하고 접속 오류를 해결하며, 기능은 여러 구성요소가 안정적으로 연결될 때 서비스가 된다는 점을 배웠습니다.

이 관심은 컴퓨터공학 전공과 웹·백엔드 학습으로 이어졌습니다. 프로젝트를 하며 데이터의 기준과 품질, 데이터를 사용하는 기능의 흐름을 살피는 데 관심을 넓혔습니다.

02

분석과 데이터 흐름

개인 프로젝트 IT-Tech Trend Analyzer에서는 여러 뉴스 채널의 기사를 공통 형식으로 정리하고 키워드를 추출했습니다. 현재와 직전 24시간의 고유 기사 수를 비교해 인기·증가 지표를 만들고, 관련 기사와 기간별 흐름을 탐색할 수 있도록 연결했습니다.

5인 팀 프로젝트 따라가요에서는 PM / Integration / DevOps와 데이터 수집·품질 흐름을 맡았습니다. 따릉이·날씨 API와 Airflow를 연결하고 원본 보존, 품질 검사, 활용 단계를 나눴습니다. 정상 0대와 누락·오류를 구분하고 OCI Object Storage의 무결성을 확인했습니다. 예측 모델은 Data/ML 담당 팀원이 개발했습니다.

03

함께 일하는 방식

문제를 입력·처리·저장·출력 단계로 나누고 로그, 상태와 수량으로 원인을 좁힙니다. 수집이 성공했는지와 다음 단계에서 신뢰해 사용할 데이터인지를 구분하고, 테스트·배포·실행 상태도 각각 확인하려고 합니다.

팀에서는 개인의 구현과 전체 결과를 구분하고, 맡은 범위와 검증 근거를 남깁니다. 설명 가능한 기준을 세우고 동료가 확인할 수 있는 경계를 만드는 일을 중요하게 생각합니다.

04

커리어 방향

데이터 분석과 데이터 엔지니어링을 주력으로 성장하고 싶습니다. 분석 결과가 신뢰할 수 있는 데이터 흐름 위에 놓이고, 서비스나 의사결정에 실제로 연결되는 과정을 배우고 기여하겠습니다.

백엔드·프론트엔드·Cloud/DevOps 경험은 그 흐름을 구현하고 전달하는 데 활용하겠습니다. 아직 검증되지 않은 분석 효과나 운영 성과를 주장하지 않고, 맡은 업무와 근거를 구분하며 경험을 쌓겠습니다.

데이터의 기준과 맥락을 살피고, 결과가 쓰이는 단계까지 연결하는 구성원으로 성장하겠습니다.
